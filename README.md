# 자율신경 아틀라스

교감신경과 부교감신경의 활동을 바꾸면서 16개 기관이 어떻게 반응하는지 애니메이션으로 보는 학습용 프로그램입니다.

## 실행

`index.html`을 내려받아 브라우저로 열면 됩니다. 설치할 것은 없습니다. 글꼴은 Google Fonts에서 불러오며, 인터넷이 없으면 시스템 글꼴로 표시됩니다.

## 구성

| 탭 | 내용 |
|---|---|
| 기관 탐색 | 교감·부교감 조절, 상황별 예시, 기관 애니메이션과 수용체별 작용 |
| 신호 경로 | 절전·절후섬유와 Nn 수용체, 땀샘과 부신수질의 예외 |
| 총정리 표 | 기관, 신경, 수용체, 작용 검색 |
| 약물 | 항콜린제, 알파효능제, 알파차단제, 베타효능제, 베타차단제의 작용과 부작용. 용량 정보는 없습니다 |
| 복습 | 생리와 약물을 합친 100문제 퀴즈. 풀 때마다 문제와 보기 순서가 바뀝니다 |
| 근거 | 참고 문헌과 확인 수준(전문, 초록, 교재) |

## 파일

- `index.html`: 프로그램 전체
- `자율신경계_검토정리.docx`: 자율신경계 노트 검토본. 수정한 부분은 파란 점선 밑줄로 표시되어 있고, 출처 확인이 더 필요한 항목은 문서에 적혀 있습니다.

## 참고

그림과 막대는 조절 방향을 이해하기 위한 교육용 모형이며 실측값이 아닙니다. 진단이나 치료, 약물 사용 판단의 근거로 쓰면 안 됩니다.
